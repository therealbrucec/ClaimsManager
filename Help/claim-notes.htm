Northbridge Assurance Claims Manager

Notes tab

File notes record what has been done and why: a telephone conversation, a decision, a reminder for whoever picks the claim up next. Everyone can add notes, adjusters included.

4 To add a note

  1. Type the note in New note.
  2. Tick Internal only if the note is for Northbridge staff and must not be shared with the insured or their representatives.
  3. Click Add note.

The list shows each note with when it was written, who by, and whether it is Internal or Shared.

Important  Notes cannot be changed or deleted once added. To correct a note, add another that says what was wrong.
