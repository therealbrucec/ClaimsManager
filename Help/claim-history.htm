Northbridge Assurance Claims Manager

History tab

The History tab is the record an auditor, a complaint or a court will be read against. It has two parts.

Status history

One line for every change of status: when it happened, who made it, the status it moved from and to, and the reason given. Reasons are typed in the Confirm decision box when the claim is moved on.

Audit trail

One line, newest first, for each thing done to the claim: when it was created, each correspondence item filed, each document added or removed, each note added, each payment recorded and each change of status. Each line shows when, who, the action and the detail.

Note  Neither list can be edited. Nothing in Claims Manager changes or deletes a history or audit line, which is the point of keeping them.
