Documents tab

The Documents tab lists every file held on the claim, newest first: photographs, receipts, invoices, estimates, reports, letters and policy documents. It includes files that arrived with inbound items as well as files added here.

4 To add documents

  1. In File the next as, choose the type of document: Photo, Receipt, Invoice, Estimate, Report, Correspondence, Policy Document or Other.
  2. Click Add documents.
  3. Select one or more files and click Open.

The files are copied into the claim's folder in the document store. The originals are not touched and can be deleted afterwards. Repeat for each type of document.

4 To look at a document

Double-click it, or select it and click Open. It opens in whichever program Windows uses for that kind of file.

4 To take a document off the claim

  1. Select the document.
  2. Click Remove, then Yes.

Removing a document takes it off the claim, but the file itself stays in the document store, so a mistake destroys nothing.

Tip  An adjuster needs something to review. A claim cannot be referred to an adjuster until it has at least one document or one inbound item. See Before a claim can move on.

Adjusters can open documents but cannot add or remove them.
