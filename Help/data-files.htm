Northbridge Assurance Claims Manager

Where your data is kept

Claims Manager keeps everything in the same folder as the program itself. Nothing is written to your user profile. When installed, that folder is:

C:\Program Files (x86)\Northbridge Assurance\Claims Manager

To see the exact paths on your computer, click About on the Help menu.

File or folderWhat it is
Claims.mdbThe database: claims, inbound items, notes, payments, history and the audit trail. Created the first time the program runs.
Documents\The document store. One folder per claim reference holds the files attached to that claim. Items still in the intake queue have their files kept here until they are filed.
demo-accounts.csvThe sign-in details for this demonstration build, and what each role may do.
ClaimsManager.chmThis help file.

Because everything is in one folder, every person who uses Claims Manager on the computer shares the same claims.

Demonstration data

The first time it runs, Claims Manager fills the database with a year of invented claims, with their payments, history and correspondence, and a few items waiting in the intake queue. The same claims are produced every time, so two demonstrations start from exactly the same book.

4 To start again with a fresh book

  1. Exit Claims Manager.
  2. In the program folder, delete Claims.mdb and the Documents folder.
  3. Start Claims Manager. It builds a new database, which takes a few seconds.
Important  Uninstalling Claims Manager removes the program but leaves the database, the documents and the sign-in file, because they were created by running it. Delete the folder afterwards to remove them.
