Northbridge Assurance Claims Manager

Signing in

Everyone signs in with their own user name. The account you sign in with carries your role, and the role decides what Claims Manager lets you do.

4 To sign in

  1. On the Start menu, click Claims Manager.
  2. Wait while the Northbridge Assurance screen reports its progress. The first time the program runs on a computer it builds its database, which takes a few seconds.
  3. In the User name box, type your user name.
  4. In the Password box, type your password.
  5. Click Sign in, or press ENTER.

The main window opens. Handlers and supervisors start on My claims; adjusters start on the Adjuster review queue. Your name and role are shown in the status bar along the bottom of the window.

Note  On this demonstration build the user names, and the single password they all share, are listed in demo-accounts.csv, in the same folder as the program. The folder is shown at the foot of the sign-in box. See Where your data is kept.

4 To sign out

  1. On the File menu, click Sign out.
  2. Click Yes to confirm. Claims Manager closes every window, restarts and returns to the sign-in box, ready for the next person.

If you cannot sign in

MessageWhat to do
There is no account called …Check the spelling of the user name. User names are not case-sensitive.
That password is not right.Type the password again, taking care over capital letters and digits.
That account is no longer active.The account has been switched off. Ask a supervisor.
No users are set up in the database.The database is incomplete. See Troubleshooting.
