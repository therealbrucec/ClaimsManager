Northbridge Assurance Claims Manager

Troubleshooting

Claims Manager cannot start: the folder cannot be written to

Claims Manager keeps its database beside the program, so it must be able to write to that folder. The installer arranges this. If you are running a copy from somewhere read-only, such as a network share or a CD, copy the whole folder to your Desktop or Documents and run it from there.

The Jet 4.0 database provider is not available

The database is reached through the Microsoft Jet 4.0 provider, which is part of Windows but exists only for 32-bit programs. The message means Claims Manager has been run as a 64-bit process. Reinstall it from the Northbridge Assurance installer, which installs the 32-bit build.

No users are set up in the database

The database was not built completely, perhaps because the program was closed during its first start. Exit Claims Manager, delete Claims.mdb from the program folder and start it again. See Where your data is kept.

A report produces a CSV file and no chart

Excel could not be started. The charts are drawn by Excel, so it must be installed on the computer. See Exporting reports.

A document will not open

Documents open in whichever program Windows uses for that type of file. If Windows asks which program to use, no program on the computer handles that type. If Claims Manager says the file cannot be found, it has been moved or deleted from the Documents folder outside Claims Manager.

Help opens, but the topics say the page cannot be displayed

Windows will not show help pages from a help file it does not trust: one opened from a network share, or one that arrived in a download or a zip file. Copy Claims Manager to the local disk. If the help file was downloaded, right-click ClaimsManager.chm, click Properties, tick Unblock and click OK.

Pressing F1 says the help file is missing

ClaimsManager.chm should be in the same folder as the program. Reinstall Claims Manager to put it back.
